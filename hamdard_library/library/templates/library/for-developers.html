For Developers

1. Purpose of Hamdard Library

The main goal of Hamdard Library is to provide a simple and easy-to-use platform for students of Jamia Hamdard to share academic resources among each other.

The core functional goals are to avoid over-engineering, keep the platform minimal, and focus on functionality and usability.

2. Tech Stack Used

  • Django
  • PostgreSQL (Neon DB)
  • Bootstrap
  • Jinja Server-Side Rendered Templates
  • Django REST Framework (API)
  • Deployment on Render

3. How to Contribute

You can contribute to the project at https://github.com/Rachit74/hamdard-library .

Contribution steps:

  1. Fork the repository
  2. Create a separate branch
  3. Work on features or fixes
  4. Open a pull request

Basic contribution guidelines:

  • Comment your code clearly
  • Follow Django and Python conventions

Proper documentation for contribution will be available soon. More details will be added to the Contribution Guide page.

API

The API endpoints are available at the API documentation.

The current API supports fetching and uploading files. A Vue.js frontend is already available at https://hamdardlibrary.vercel.app/ .

If you want to build your own frontend using any framework, feel free to do so using the provided API.
