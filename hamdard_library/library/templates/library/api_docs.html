API Reference

Base URL: https://hamdardlibrary.onrender.com/

🔐 Authentication /api/auth/

POST /api/auth/register/

Register a new user account.

Body: username, email, password
POST /api/auth/login/

Login and receive an auth token.

Body: username, password
DELETE /api/auth/delete/

Delete the authenticated user's account. Requires auth token.

📁 Library /api/files/

GET /api/files/

Returns all approved files.

POST /api/files/create/

Upload a new file. Requires auth token.

Body: title, file, description (optional)
DELETE /api/files/delete/{file_id}/

Delete a file by ID. Requires auth token and ownership.

GET /api/files/unapproved/

Returns all unapproved files. Admin only.

POST /api/files/approve/{file_id}/

Approve a file to make it publicly visible. Admin only.
